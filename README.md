# 解方程计算器（一元一次 / 一元二次）

一个「输入方程 → 自动求解 → 给出分步讲解」的小软件。支持等号两边都出现未知数、括号、小数、分数，
全部用**精确有理数 + 根式化简**计算（不是浮点近似），因此 `x²+x-1=0` 会得到 `(-1 ± √5)/2` 而不是 `0.618034`。

## 打开就能用

- **单文件版（推荐）**：双击 [`index.html`](index.html)（也可用浏览器直接打开）。
  62 KB 左右，零依赖、纯离线，代码全部内联在这一个文件里，随便拷到哪台电脑都能跑。
- **源码版**：打开 [`src/ui/template.html`](src/ui/template.html)（需要连同 `src/` 目录一起保留）。
- **命令行版**：见下方[命令行版用法](#命令行版用法)。

## 命令行版用法

在 `equation-solver` 目录里执行（也可以在任意目录用绝对路径调用）：

```bash
node cli.js "2x + 3 = 5x - 9"        # 打印完整分步解答（移项、判别式、验算、结论）
node cli.js -s "x^2 - 5x + 6 = 0"    # -s / --short：只打印解集
node cli.js --help                   # 查看用法
```

**批量求解**：不提供方程时，从标准输入逐行读取（空行忽略），`-s` 同样适用。

```bash
# PowerShell
@('2x+3=5x-9','x^2-5x+6=0','x^2+2x+10=0') | node cli.js -s
Get-Content examples/equations.txt | node cli.js -s      # 读文件（附了一个样例输入文件）

# bash / zsh
cat examples/equations.txt | node cli.js -s
```

**退出码**：全部求解成功返回 `0`；有任何一个方程报错、或没有输入时返回 `1`，方便脚本判断。

```powershell
node cli.js -s "x^2-9=0"   # x₁ = -3，x₂ = 3        退出码 0
node cli.js -s "1/x=2"     # 未知数不能出现在分母里…  退出码 1
```

**加引号很重要**：方程里常含 `^`，而 `^` 在 cmd.exe 中是转义字符——不加引号时 `x^2` 会变成 `x2`，
被当成 `x×2` 求解，得到完全不同的答案：

```bat
:: 错误写法：cmd 把 ^ 吃掉了，结果变成 x = 1
node cli.js -s x^2-2=0

:: 正确写法：加引号（引号内的 ^ 不会被转义）
node cli.js -s "x^2-2=0"

:: 或者用上标字符，彻底绕开转义问题
node cli.js -s "x²-2=0"
```

PowerShell 里 `^` 不特殊，但仍建议始终加引号，避免 `|`、`&`、`>` 被 shell 解释。

## 在 PowerShell 里配置 eqsolve 函数

把 [`shell/eqsolve-profile.ps1`](shell/eqsolve-profile.ps1) 的内容追加到你的 PowerShell 配置文件
（`$PROFILE` 一般指向 `%USERPROFILE%\Documents\WindowsPowerShell\Microsoft.PowerShell_profile.ps1`），
开新窗口（或 `. $PROFILE`）后即可在**任何目录**直接使用。

先告诉函数仓库放在哪（含 `cli.js` 的那个目录），二选一：设环境变量，或改脚本里的 `$defaultRoot`：

```powershell
$env:EQ_SOLVER_ROOT = 'C:\src\equation-solver'

eqsolve "2x + 3 = 5x - 9"                  # 完整解答
eqsolve -s "x^2 - 5x + 6 = 0"              # 只要解集
eqsolve --web                              # 打开图形版（默认浏览器），等价于 -w
Get-Content .\examples\equations.txt | eqsolve -s
eqsolve --help
```

函数做的事：把参数原样转给 `cli.js`；用管道传入时自动按行批量求解；没有参数时打印用法而不是傻等输入；
带 `--web`/`-w` 时不启动 node，而是用 `Start-Process` 打开单文件 HTML 版（先在
`$EQ_SOLVER_ROOT` 下找 `index.html`，找不到再找它的上一级目录，都没有就提示先跑 `build.js`）。
它还会在调用期间把 `[Console]::OutputEncoding` 与 `$OutputEncoding` 临时切到 UTF-8 并在结束后还原——
否则 Windows PowerShell 5.1（系统编码 gb2312）会把 node 输出的中文显示成乱码，管道里的 `²` 也会被吃掉。

相关文件（都放在 `shell/` 下，可直接复用或重新安装）：

| 文件 | 用途 |
| --- | --- |
| `shell/eqsolve-profile.ps1` | 函数源码，追加到配置文件即可安装（可重复安装，幂等） |
| `shell/verify-profile.ps1` | 自检脚本：加载配置文件后跑 28 项检查（中文解码、管道、退出码、编码还原、`--web` 路径解析） |
| `shell/probe-autoload.ps1` | 验证"全新 PowerShell 窗口自动加载配置" |

安装前建议先把原配置文件备份一份（例如存为 `Microsoft.PowerShell_profile.ps1.bak`）；
本脚本可重复追加，同名函数只有一份生效。

> ⚠️ 维护提示：这几个 `.ps1` **必须是纯 ASCII**（或用 UTF-8 BOM 保存）。
> Windows PowerShell 5.1 读取无 BOM 的脚本时按系统 ANSI（本机为 gb2312）解码，
> 注释里的中文可能把行尾换行吞掉，导致下一行代码被合并进注释而静默失效——
> 本次调试时就被这个坑绊过一次。因此 HTML 的中文文件名是用
> `[char]0x89E3 ...` 码点拼出来的（见 `eqsolve-profile.ps1` 里的注释）。

## 支持的方程与输入写法

| 类型 | 例子 | 结果 |
| --- | --- | --- |
| 一元一次 | `2x + 3 = 5x - 9` | `x = 4` |
| 一元一次（分数系数） | `x/2 + 1 = 3` | `x = 4` |
| 一元二次（能因式分解） | `x² - 5x + 6 = 0` | `x₁ = 2，x₂ = 3` |
| 一元二次（无理根） | `x² + x - 1 = 0` | `x₁ = (-1 - √5)/2，x₂ = (-1 + √5)/2` |
| 一元二次（二重根） | `x² - 6x + 9 = 0` | `x = 3`（二重根） |
| 一元二次（复数根） | `x² + 2x + 10 = 0` | `x₁ = -1 + 3i，x₂ = -1 - 3i` |
| 恒等式 | `x + 1 = x + 1` | 任意实数（无穷多解） |
| 无解 | `x + 1 = x + 2` | 无解 |

输入时这些都等价：`x^2`、`x²`、`X`（大小写不敏感）；`2x` 与 `2*x`；`1/2` 与 `0.5`；
乘号可以用 `×`、`·`；全角括号、全角数字、`＝` 都能识别。只写一边（如 `x²-5x+6`）会当成 `= 0`。

## 软件会给出什么

1. **原方程与标准形式** —— 展开括号、移项、合并同类项，得到 `ax² + bx + c = 0`；
2. **方程类型与系数** —— 说明是一元一次还是一元二次，列出 `a`、`b`、`c`；
3. **判别式 Δ** —— 算 `b² - 4ac`，说明 Δ > 0 / = 0 / < 0 分别对应什么；
4. **求解过程** —— 一次方程：移项 + 两边同除；二次方程：因式分解 / 求根公式，根式会**化简**
   （例如 `√28 = 2√7`），复数根写成 `a ± bi`；
5. **代入验算** —— 把每个根代回标准形式，显示残差（约等于 0）；
6. **函数图像** —— 把方程看成直线或抛物线，画出曲线并标出交点（根）和顶点；
7. **小数近似** —— 无理根、复数根同时给出近似值；分数解同时给出小数（如 `3/2 = 1.5`）。

界面上的「函数图像」「解题步骤」「历史记录」三块都是**折叠式**（默认收起，点击标题展开，
展开状态会被记住，下次打开保持你上次的选择）；解集卡片始终显示在最上面。页面不再提供示例按钮，
需要输入时按提示直接键入方程即可。

**讲解会自动精简**：如果第一步"化简两边"之后方程就已经是 `x = c` 的形状（例如 `x=25/180`、
`x + 3 - 3 = 7`），讲解只会给出 4 步 —— 原方程 → 化简后已经得到解 → 代入验算 → 结论，
不再重复"移项 / 识别系数 / 两边同除"这些已经没有作用的环节；一般方程（如 `2x=10`、`3(x-2)=x+4`）
仍然是完整的移项 + 合并同类项 + 求根讲解。

## 原理简述

- **解析**：先规范化输入（上标、全角、乘号…），再分词，用递归下降语法分析把两边都化简成系数数组
  （下标即次数），`左边 - 右边` 得到标准形式；`2x`、`3(x+1)`、`(x+1)(x-2)` 这类隐式乘法统一按乘法处理。
- **求解**：
  - 0 次：`0 = 0` 恒等式（无穷多解）或 `c = 0` 矛盾（无解）；
  - 1 次：`ax + b = 0 → x = -b/a`；
  - 2 次：`Δ = b² - 4ac`；Δ > 0 用 `x = (-b ± √Δ)/(2a)`，并把 `√Δ` 化简成 `k√M/Q`
    （Δ 是完全平方数时直接得到有理根，同时给出因式分解）；Δ = 0 得二重根；Δ < 0 得共轭虚根。
- **精度**：所有系数都是 `BigInt` 分子/分母的有理数，全程精确；只有需要「小数近似」时才转成浮点数。

## 已知限制

- 只支持一元一次和一元二次方程；次数更高的（如 `x³ = 8`）会明确提示不支持。
- 未知数不能出现在分母里（如 `1/x = 2`），因为本工具求解的是整式方程。
- 一次/二次以外的情形（例如绝对值、根号内包含未知数）暂不支持，输入含未知数的根号会提示无法识别。
