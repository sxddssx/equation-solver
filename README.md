# 数学计算器（方程 · 算式 · 绘图）

一个「输入一行东西 → 自动判断是什么 → 给出精确结果和讲解」的小软件，三种工作模式共用一套引擎：

| 模式 | 你输入 | 它做什么 |
| --- | --- | --- |
| **解方程** | `2x+3=5x-9`、`x²-5x+6=0`、`x^3-8=0` | 移项合并 → 判别式 → 因式分解 / 求根公式 / 有理根 + 数值求根，给分步讲解和代入验算 |
| **算数值** | `sin(30)+1/2`、`5!`、`(3+4i)/(1-2i)`、`nCr(5,2)` | 直接算出一个数，支持复数、函数、阶乘、排列组合，可切换角度制 / 弧度制 |
| **画图像** | `plot x^2-4`、`plot sin(x)`、`plot 1/x` | 自动识别函数类型、自动定坐标范围、画出曲线并标出交点 / 顶点 / 渐近线 |

方程求解全部用**精确有理数（BigInt 分数）+ 根式化简**，所以 `x²+x-1=0` 会得到 `(-1 ± √5)/2`，
而不是 `0.618034`；只有高次方程的「无有理根因式」才会转成数值解，并且明确标上 `≈`。

## 命令行版用法

在 `equation-solver` 目录里执行（也可以在任意目录用绝对路径调用）：

```bash
node cli.js "2x + 3 = 5x - 9"        # 方程 → 打印完整分步解答（移项、判别式、验算、结论）
node cli.js -s "x^2 - 5x + 6 = 0"    # -s / --short：只打印解集
node cli.js "x^3 - 8 = 0"            # 三次及以上：有理根 + 降次，必要时给数值根
node cli.js "sin(30) + 1/2"          # 纯数值算式 → 自动按计算模式处理
node cli.js -s "(3+4i)/(1-2i)"       # 复数结果：-1 + 2i
node cli.js plot "sin(x)" -360 360   # 在终端里画函数图像（可给出 x 范围）
node cli.js --rad "sin(pi/2)"        # 三角函数改用弧度制（默认角度制）
node cli.js --help                   # 查看用法
```

**批量计算**：不提供输入时，从标准输入逐行读取（空行忽略），`-s` 同样适用；
每行都可以是方程、算式或 `plot …`，`ans` 可以在后面的行里引用上一行的结果。

```bash
# PowerShell
Get-Content examples/equations.txt | node cli.js -s   # 附了一个混合样例文件
@('2x+3=5x-9','x^3-x-1=0','sin(30)','plot 1/x') | node cli.js -s
```

**退出码**：全部计算成功返回 `0`；有任何一个报错、或没有输入时返回 `1`，方便脚本判断。

**加引号很重要**：方程里常含 `^`，而 `^` 在 cmd.exe 中是转义字符——不加引号时 `x^2` 会变成 `x2`，
被当成 `x×2` 求解，得到完全不同的答案：

```bat
:: 错误写法：cmd 把 ^ 吃掉了，结果变成 x = 1
node cli.js -s x^2-2=0

:: 正确写法：加引号（引号内的 ^ 不会被转义）
node cli.js -s "x^2-2=0"

:: 或者用上标字符，彻底绕开转义问题
node cli.js -s "x²-2=0"
```

PowerShell 里 `^` 不特殊，但仍建议始终加引号，避免 `|`、`&`、`>` 被 shell 解释。

## 在 PowerShell 里配置 eqsolve 函数

把 [`shell/eqsolve-profile.ps1`](shell/eqsolve-profile.ps1) 的内容追加到你的 PowerShell 配置文件
（`$PROFILE` 一般指向 `%USERPROFILE%\Documents\WindowsPowerShell\Microsoft.PowerShell_profile.ps1`），
开新窗口（或 `. $PROFILE`）后即可在**任何目录**直接使用。

先告诉函数仓库放在哪（含 `cli.js` 的那个目录），二选一：设环境变量，或改脚本里的 `$defaultRoot`：

```powershell
$env:EQ_SOLVER_ROOT = 'D:\Codefiles\equation-solver'

eqsolve "2x + 3 = 5x - 9"                  # 完整解答
eqsolve -s "x^2 - 5x + 6 = 0"              # 只要解集
eqsolve "sin(30)+1/2"                      # 算式照样走（函数把参数原样传给 cli.js）
eqsolve plot "sin(x)"                      # 终端里画图
eqsolve --web                              # 打开图形版（默认浏览器），等价于 -w
Get-Content .\examples\equations.txt | eqsolve -s
eqsolve --help
```

函数做的事：把参数原样转给 `cli.js`；用管道传入时自动按行批量计算；没有参数时打印用法而不是傻等输入；
带 `--web`/`-w` 时不启动 node，而是用 `Start-Process` 打开单文件 HTML 版（先在
`$EQ_SOLVER_ROOT` 下找 `index.html`，找不到再找它的上一级目录，都没有就提示先跑 `build.js`）。
它还会在调用期间把 `[Console]::OutputEncoding` 与 `$OutputEncoding` 临时切到 UTF-8 并在结束后还原——
否则 Windows PowerShell 5.1（系统编码 gb2312）会把 node 输出的中文显示成乱码，管道里的 `²` 也会被吃掉。

相关文件（都放在 `shell/` 下，可直接复用或重新安装）：

## 输入是怎么分流的

`compute()` 只做一件事：看输入长什么样，决定用哪个模式。

| 输入特征 | 走哪条路 | 例子 |
| --- | --- | --- |
| 以 `plot` 开头 | 绘图 | `plot x^2-4`、`plot sin(x)`、`plot 1/x` |
| 含 `=` | 解方程 | `2x+3=5x-9`、`x²-5x+6=0` |
| 不含 `=`，但含未知数 | 当作 `… = 0` 解方程 | `x²-5x+6`、`x^3-8` |
| 不含 `=`、也不含未知数 | 算数值 | `2^10`、`sin(30)+1/2`、`5!`、`(3+4i)/(1-2i)` |

也就是说：**有没有未知数**是分水岭。`2*3` 现在会直接算出 `6`（老版本会把它当方程说"无解"）。

## 方程能做到什么

| 类型 | 例子 | 结果 |
| --- | --- | --- |
| 一元一次 | `2x + 3 = 5x - 9` | `x = 4` |
| 一元一次（分数系数） | `x/2 + 1 = 3` | `x = 4` |
| 一元二次（能因式分解） | `x² - 5x + 6 = 0` | `x₁ = 2，x₂ = 3` |
| 一元二次（无理根） | `x² + x - 1 = 0` | `x₁ = (-1 - √5)/2，x₂ = (-1 + √5)/2` |
| 一元二次（二重根） | `x² - 6x + 9 = 0` | `x = 3`（二重根） |
| 一元二次（复数根） | `x² + 2x + 10 = 0` | `x₁ = -1 + 3i，x₂ = -1 - 3i` |
| **高次（能提有理根）** | `x^3 - 6x^2 + 11x - 6 = 0` | `x₁ = 1，x₂ = 2，x₃ = 3` |
| **高次（降到二次收尾）** | `x^3 = 8` | `x₁ = 2，x₂ = -1 + √3i，x₃ = -1 - √3i` |
| **高次（没有有理根）** | `x^3 - x - 1 = 0` | `x₁ ≈ 1.324718，x₂ ≈ -0.662359 + 0.56228i，x₃ ≈ -0.662359 - 0.56228i` |
| 恒等式 | `x + 1 = x + 1` | 任意实数（无穷多解） |
| 无解 | `x + 1 = x + 2` | 无解 |

输入时这些都等价：`x^2`、`x²`、`X`（大小写不敏感）；`2x` 与 `2*x`；`1/2` 与 `0.5`；
乘号可以用 `×`、`·`；全角括号、全角数字、`＝` 都能识别。只写一边（如 `x²-5x+6`）会当成 `= 0`。

三次及以上是这样解的（`src/45-polyroots.js`）：

1. 先把 `x = 0` 的根整体提出来；
2. 用**有理根定理**列出全部候选 `±p/q`，逐个试根，命中就用**综合除法**降一次，直到剩下一次或二次因式；
3. 剩下的一次 / 二次因式照样用求根公式，得到精确的有理数根 / 根式根 / 复数根；
4. 如果剩下的次数仍然 ≥ 3（说明没有有理根），用 **Durand–Kerner 迭代**同时逼近全部复根，
   给出带 `≈` 的数值解，并做残差检查。数值求根支持到 10 次。

## 算式（计算模式）能做到什么

| 类别 | 可用的东西 |
| --- | --- |
| 运算 | `+ - * / ^ !`、括号、隐式乘法（`2x`、`3(1+2)`、`2pi`） |
| 常数 | `pi`（`π`）、`e`、`i`（虚数单位）、`tau`、`phi`、`ans`（上一次的结果） |
| 三角 | `sin cos tan asin acos atan`（受角度制 / 弧度制影响） |
| 双曲 | `sinh cosh tanh asinh acosh atanh` |
| 指数对数 | `exp ln log log10 log2`（`log(x)` 是常用对数，`log(底, 真数)` 指定底数） |
| 取整与符号 | `floor ceil round trunc sign abs mod(a,b)` |
| 组合数学 | `gamma(x)`、`nPr(n,r)`、`nCr(n,r)`、`x!`（小数/负数走 Gamma 函数） |
| 其它 | `sqrt cbrt hypot(a,b) min max deg(x) rad(x)` |

- **角度制 / 弧度制**：默认**角度制**（`sin(30) = 0.5`），界面上有按钮切换，命令行用 `--deg` / `--rad`。
  切换后 `sin(pi/2)` 才会等于 `1`。
- **复数**：全程按复数算，`sqrt(-4) = 2i`、`i^2 = -1`、`e^(i*pi) = -1`。
  结果落在实轴上时就显示成实数，否则显示 `a + bi`。
- **精确分数**：结果是「好看」的有理数时会额外给分数写法，例如 `1/3+1/6` → `0.5（= 1/2）`，
  `0.1+0.2` → `0.3（= 3/10）`。
- **阶乘与幂的结合顺序**：默认 `2^3! = 2^(3!) = 64`；命令行加 `--factpower` 后变成 `(2^3)! = 40320`
  （对应参考实现的 `modefactpower`）。

## 绘图能做到什么

- 任意表达式：多项式、三角函数、指数对数、根式、反比例、带绝对值的组合都能画。
- **自动识别函数类型**并在标题上显示：一次函数 / 二次函数 / 多项式函数 / 反比例函数 /
  平移反比例函数 / 常数函数 / 一般函数。
- **自动定范围**：多项式按根和顶点选窗口；三角函数在角度制下给 ±360°、弧度制下给 ±2π；
  左右一大片没定义时（如 `√x`、`ln x`）会自动把窗口收到有定义的一侧；
  y 方向对极点附近做稳健裁剪，既不会被一两个爆炸值撑坏，也不会看不到相对变化。
- 标出**与 x 轴的交点**（二分法精确定位）、二次函数的**顶点**、反比例函数的**竖直渐近线**（虚线）。
- 极点处曲线**断开**，不会画出一条假的竖线。
- 网页版可以手动填 x 范围，点「自动」回到自适应；命令行版直接给数字：`plot "sin(x)" -360 360`。

## 软件会给出什么

1. **原方程与标准形式** —— 展开括号、移项、合并同类项，得到 `ax² + bx + c = 0`（或 `aₙxⁿ + … = 0`）；
2. **方程类型与系数** —— 一元一次 / 一元二次 / 高次，列出 `a`、`b`、`c`；
3. **判别式 Δ** —— 算 `b² - 4ac`，说明 Δ > 0 / = 0 / < 0 分别对应什么（高次方程走因式分解讲解）；
4. **求解过程** —— 一次方程：移项 + 两边同除；二次方程：因式分解 / 求根公式，根式会**化简**
   （例如 `√28 = 2√7`），复数根写成 `a ± bi`；高次方程：有理根候选、试根、综合除法、剩余因式收尾；
5. **代入验算** —— 把每个根代回标准形式，显示残差（约等于 0）；
6. **函数图像** —— 画出曲线并标出交点、顶点、渐近线；
7. **小数近似** —— 无理根、复数根同时给出近似值；分数解同时给出小数（如 `3/2 = 1.5`）。

界面上的「函数图像」「解题步骤」「历史记录」三块都是**折叠式**（默认收起，点击标题展开，
展开状态会被记住，下次打开保持你上次的选择）；解集卡片始终显示在最上面。
连按两次「计算」不会重复记录历史；算式结果只有一张结果卡（没有步骤和图像）。

**讲解会自动精简**：如果第一步"化简两边"之后方程就已经是 `x = c` 的形状（例如 `x=25/180`、
`x + 3 - 3 = 7`），讲解只会给出 4 步 —— 原方程 → 化简后已经得到解 → 代入验算 → 结论，
不再重复"移项 / 识别系数 / 两边同除"这些已经没有作用的环节；一般方程（如 `2x=10`、`3(x-2)=x+4`）
仍然是完整的移项 + 合并同类项 + 求根讲解。

## 原理简述

- **两条解析路线**：
  - 方程走「精确路线」：先规范化输入（上标、全角、乘号…），再分词，用递归下降把两边都化简成**系数数组**
    （下标即次数），`左边 - 右边` 得到标准形式；`2x`、`3(x+1)`、`(x+1)(x-2)` 这类隐式乘法统一按乘法处理。
  - 算式 / 绘图走「通用路线」：同一套词法 + 语法树，但值域是**复数**，函数库齐全，
    可以算 `sin`、`log`、阶乘、Gamma，也能把 `x` 当自变量逐点求值。
- **求解**：
  - 0 次：`0 = 0` 恒等式（无穷多解）或 `c = 0` 矛盾（无解）；
  - 1 次：`ax + b = 0 → x = -b/a`；
  - 2 次：`Δ = b² - 4ac`；Δ > 0 用 `x = (-b ± √Δ)/(2a)`，并把 `√Δ` 化简成 `k√M/Q`
    （Δ 是完全平方数时直接得到有理根，同时给出因式分解）；Δ = 0 得二重根；Δ < 0 得共轭虚根；
  - 高次：有理根定理 + 综合除法降次，剩下二次用求根公式，剩下三次及以上用 Durand–Kerner 迭代。
- **精度**：方程里的系数都是 `BigInt` 分子/分母的有理数，全程精确；只有需要「小数近似」
  或「数值求根」时才转成浮点数，并把这类结果明确标成 `≈`。
- **绘图**：先判断表达式能否用多项式解析器精确处理（是就拿到精确系数，能解析出根和顶点），
  否则按采样点做类型识别（反比例用三点插值解 `(x-a)(y-b) = k`，比最小二乘稳），
  再按函数特性选窗口、在极点处断开折线、二分法定位交点。

## 已知限制

- 方程只支持**一个未知数**，且必须是整式方程：未知数不能出现在分母（`1/x = 2`）或
  `sin`、`log`、`√` 这类函数里（`sin(x) = 0.5` 会明确提示）。
- 数值求根只支持 10 次以内；没有有理根的高次方程给的是近似解（带 `≈`）。
- 算式模式只算具体数值，不能带未知数（留空未知数用 `plot` 画函数）。
- 绘图的函数必须是**实值**函数（`x` 代进去得到实数），虚数值的点会被跳过。

## 二次开发

改完 `src/` 下的任意文件后重新运行 `node build.js` 即可刷新单文件成品；
若只改了界面，也可以直接刷新源码版 `src/ui/template.html`。
新增模块时记得同时更新 `src/index.js`（Node）、`build.js` 的 `FILES`（打包）
和 `src/ui/template.html` 里的 `<script>` 列表（源码版）。
